PROY-STEAM-LATAM // GOBIERNO TI ITIL v4 • ISO/IEC 20000

PROY-Steam LatAm (ITIL v4 & ISO/IEC 20000)

Diseño de un modelo híbrido de Service Desk orientado a plataformas de distribución digital y soporte regional en Latinoamérica, estructurando la operación de incidentes, requerimientos y continuidad del servicio.

Componentes Técnicos Documentados:
  • › Modelo Híbrido de Service Desk & Matrices RACI: Definición de responsabilidades entre niveles N1, N2 y N3 para despacho y escalamiento regional.
  • › Estructura SLA / OLA: Acuerdos de nivel de servicio y acuerdos operativos internos con tiempos objetivo de respuesta y resolución por severidad.
  • › Análisis Ishikawa & Gestión Financiera: Diagnóstico de causa raíz de fallos recurrentes y control presupuestario/OpEx asociado a la operación de soporte.
ITIL v4 ISO/IEC 20000 Service Desk Híbrido Matrices RACI SLA / OLA Ishikawa Gestión Financiera TI
EA-RETAIL-OMNICANAL // TOGAF ADM Fases A–H

Arquitectura Empresarial & Retail Omnicanal (TOGAF)

Blueprint de transformación empresarial para integrar tiendas físicas y comercio digital bajo una operación omnicanal unificada, alineando procesos de negocio, datos, aplicaciones e infraestructura tecnológica.

Componentes Técnicos Documentados:
  • › Aplicación de Fases A–H (TOGAF ADM): Desde la Visión de Arquitectura y análisis de brechas hasta la planificación de migración y gobernanza de implementación.
  • › Análisis FODA & Mapas de Soporte Tecnológico: Diagnóstico estratégico de capacidades y trazado de aplicaciones, integraciones y plataformas de soporte.
  • › Modelo Antifraude en Pasarelas de Pago: Reglas de validación de riesgo transaccional, verificación en checkout omnicanal y monitoreo de anomalías.
TOGAF Fases A–H Arquitectura Empresarial Análisis FODA Mapas Tecnológicos Antifraude & Pagos
PARKING-DB // SISTEMA TRANSACCIONAL Full-Stack • MySQL

ParkingDB & Facturación Vehicular

Sistema transaccional full-stack para control de ingresos vehiculares, asignación de espacios por zona y facturación automática en tiempo real con consistencia garantizada en base de datos.

Componentes Técnicos Documentados:
  • › Backend con Node.js & Express: Endpoints REST para registro de entradas/salidas, cálculo de estadía y emisión estructurada de comprobantes.
  • › Motor MySQL & Triggers SQL: Esquema normalizado con triggers SQL para cálculo tarifario automático, actualización de cupos y registro de auditoría.
  • › Control de Acceso por Roles (RBAC): Gestión diferenciada de permisos para administradores, supervisores y operadores de caja.
Node.js Express MySQL Triggers SQL Control por Roles (RBAC)
ARTESANET // PLATAFORMA WEB E-Commerce & Datos

ArtesaNet (E-Commerce & Trazabilidad)

Plataforma web de comercio electrónico orientada a la gestión estructurada de catálogo artesanal, trazabilidad de órdenes y generación de indicadores para análisis comercial de ventas.

Componentes Técnicos Documentados:
  • › Gestión de Catálogo & Stock: Administración modular de productos por categoría, atributos de origen artesanal y control de existencias.
  • › Trazabilidad de Pedidos: Seguimiento completo del ciclo de orden, despacho y estado de entrega entre productor y cliente final.
  • › Análisis de Ventas: Registro estructurado de transacciones orientado a reportes de rotación, ingresos y desempeño por línea de producto.
E-Commerce Trazabilidad Gestión de Catálogo Análisis de Ventas Full-Stack Web
MCP-EXCEL-BRIDGE // AUTOMATIZACIÓN IA MODEL CONTEXT PROTOCOL (MCP) // ENTORNO LOCAL

Automatización IA & Servidor MCP para Hojas de Cálculo Excel Locales

Implementación de un servidor basado en el estándar Model Context Protocol (MCP) para integrar asistentes de inteligencia artificial directamente con hojas de cálculo Excel locales. Permite consultar, validar esquemas, auditar consistencia tabular y automatizar operaciones sobre libros locales sin subir archivos sensibles a servicios externos.

Arquitectura de Integración MCP
Estándar: Model Context Protocol
Fuente de Datos: Excel Local (.xlsx)
Ejecución: 100% Localhost
Motor Tabular: Python / Validación
Componentes Técnicos Documentados:
01 // Puente de Protocolo MCP Exposición de herramientas tipadas (lectura por hoja, filtrado de filas y escritura controlada) consumibles por asistentes de IA compatibles con MCP.
02 // Validación y Auditoría Tabular Verificación automática de encabezados, tipos de datos y reglas de consistencia numérica antes de consolidar reportes.
03 // Soberanía de Datos Locales Procesamiento directo sobre el sistema de archivos local para proteger la confidencialidad operativa de las hojas de cálculo.
Model Context Protocol (MCP) Automatización IA Excel Local Python Flujos ETL Procesamiento Local
